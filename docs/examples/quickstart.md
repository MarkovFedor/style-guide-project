# Запуск backend локально

Фрагмент инструкции для разработчика, который впервые запускает MVP доставки еды. Цель — получить основной API на порту 8000 и клиент ресторана на порту 8001.

## Требования

Нужны Git, Docker с Docker Compose v2 и GNU Make. Порты 5432, 8000 и 8001 должны быть свободны. Исходная версия: `89a3abe1c0ff8a86bf2aad9f09bc91669c58941f`.

Команды ниже сверены с конфигурацией и `Makefile`; выполнение самого backend в рамках этой лабораторной не проводилось. Используйте локальную учебную среду без ценных данных: команда `make seed` записывает демонстрационные данные.

## Шаги

1. Клонируйте репозиторий и перейдите в его корень.

   ```bash
   git clone https://github.com/MarkovFedor/mvp-delivery-backend.git
   cd mvp-delivery-backend
   git checkout 89a3abe1c0ff8a86bf2aad9f09bc91669c58941f
   ```

2. Создайте в корне файл `.env` с локальными настройками. Значение пароля ниже учебное; замените его. Не публикуйте `.env`.

   ```dotenv
   POSTGRES_USER=delivery
   POSTGRES_PASSWORD=local_training_only
   POSTGRES_DB=delivery
   POSTGRES_HOST=db
   POSTGRES_HOST_CONTAINERED=db
   POSTGRES_PORT=5432
   ```

3. Соберите и запустите контейнеры из корня репозитория.

   ```bash
   docker compose up -d --build
   docker compose exec db pg_isready -U delivery -d delivery
   ```

   Дождитесь сообщения `accepting connections`. `depends_on` задаёт порядок запуска, но не гарантирует готовность базы. Если проверка неуспешна, повторите её после запуска PostgreSQL.

4. Примените миграции, затем загрузите демонстрационные данные.

   ```bash
   make migrate
   make seed
   ```

## Проверка результата

Откройте [Swagger UI основного API](http://localhost:8000/docs) и [Swagger UI клиента ресторана](http://localhost:8001/docs). Обе страницы должны показать доступные операции. Команда `docker compose ps` помогает проверить состояние контейнеров.

Для запуска тестов внутри контейнера используйте `make test`. Локальная цель в `Makefile` называется `make local_test`; для неё дополнительно нужны локальные зависимости и настройки тестовой базы.

## Возможные ошибки

| Симптом | Что проверить | Следующее действие |
| --- | --- | --- |
| Порт занят | Другие приложения на 5432, 8000, 8001 | Освободите порт перед запуском |
| Миграция не подключается к базе | Готовность PostgreSQL и значения `.env` | Проверьте `docker compose logs db`, затем повторите миграцию |
| API недоступен | Состояние контейнера `app` | Проверьте `docker compose logs app` |

## Ограничения

Клиент ресторана настроен на ресторан с идентификатором `1`. Загрузка данных не является резервным копированием. Остановить среду можно командой `docker compose down`; не добавляйте `-v`, если хотите сохранить том базы.
