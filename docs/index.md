# Стайлгайд документации MVP доставки еды

Версия 1.0 · 26 ноября 2026 года · Владелец: Фёдор Марков.

Руководство задаёт единые правила для русскоязычных README, инструкций запуска, справочников API и архитектурных описаний проекта [mvp-delivery-backend](https://github.com/MarkovFedor/mvp-delivery-backend).

## Начало работы

1. Определите читателя и тип документа по [правилам структуры](guide/structure.md).
2. Сверьте названия со [словарём](guide/terms.md).
3. Примените [языковые правила](guide/language.md) и [оформление Markdown](guide/markdown.md).
4. Проверьте команды по [правилам API](guide/api.md).
5. Пройдите [проверку качества](guide/quality.md).

## Что подтверждено

Объект изучен по коммиту `89a3abe1c0ff8a86bf2aad9f09bc91669c58941f`. Это MVP backend на FastAPI с PostgreSQL и отдельным клиентом ресторана. В коде есть упрощения; их нужно явно сохранять в документации. Примеры здесь не означают, что backend был запущен или прошёл приёмочное тестирование.

[Отчёт по лабораторной](lab-report.md) содержит теоретические ответы и соответствие пунктам задания. [Протокол апробации](examples/validation.md) показывает применение правил к двум фрагментам.
